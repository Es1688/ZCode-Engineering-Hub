# AGENTS.md — ZCode Engineering Hub

## Что это за проект
Метапроект кластера `~/work`: стандарт инженерной среды на базе ZCode — концепция,
техпроект с журналами выполнения Фаз I–III (`ZCODE-HUB-DESIGN.md`), принятые ADR,
эталонные шаблоны для новых проектов и исходники плагинов. Рядом лежит эталонный
импорт upstream-скилла adversarial-review — это отдельный git-репозиторий, в данный
репозиторий не входит.

## Структура
| Путь | Что это | Можно менять? |
|---|---|---|
| `ZCode Engineering Hub.md` | исходная концепция (16 пунктов, 4 фазы) | да; исторический документ, задним числом не переписывать |
| `ZCODE-HUB-DESIGN.md` | техпроект: архитектура, стандарты, журналы Фаз I–III | да; журналы дополняются хронологически, старые записи не переписывать |
| `Совместимость ZCode с Engineering Hub и скиллом adversarial-review.md` | ADR-001 о совместимости (вариант B) | нет (accepted ADR) |
| `docs/adr/` | принятые ADR кластера | да (новые ADR дописываются) |
| `templates/` | эталонные шаблоны стандарта (project.yaml, AGENTS L1, task-context, ADR, gitignore) | осторожно — эталон, их копируют новые проекты |
| `plugins/` | маркетплейс и исходники плагинов (adversarial-review) | да |
| `audit/` | отчёт аудита от 28.09.2026 | нет (снимок) |
| `runner.md`, `SKILL.md` | рабочие материалы порта протокола adversarial-review | да |
| `adversarial-review-master/` | отдельный git-репозиторий (upstream-импорт) | нет; в git hub не входит (.gitignore) |

## Ключевые правила
- Каталог — источник истины стандарта; изменения через задачу
  (`git-start-task` → `git-finish-task`).
- Шаблоны `templates/` менять только осознанно и через задачу.
- Журналы техпроекта ведутся хронологически.

## Соглашения
- Язык: код и коммиты — английский; документация — русский.
- Деплой/пуш — только с подтверждения пользователя (Level 0 + project.yaml).
